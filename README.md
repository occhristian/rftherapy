# RF Therapy website

Standalone responsive website prototype for RF Therapy — Relate and Flourish.

Visual direction: forest green, sage/olive, warm cream, muted gold, serif-led luxury typography, botanical line art, generous whitespace, soft organic geometry.

Includes: hero, about, approach, services, journey, consent-aware client stories, booking request UI, FAQ, contact, responsive mobile layout, and inline SVG brand-inspired artwork.

Before launch, connect the booking form to a secure scheduling/backend service and add verified practitioner credentials, fees, cancellation policy, privacy policy, safeguarding/emergency information, exact service scope, and any applicable professional/regulatory disclosures.
